## Flagged Assumptions

- **FA-9.04-1.** The test harness wraps each test in a transaction (RefreshDatabase); `DB::transaction` in the action is a savepoint, so the unique-recovery catch must sit **outside** the action's transaction closure, otherwise the outer test transaction is left aborted on MySQL. SQLite tolerates either; keep the catch outside.
- **FA-9.04-2.** `insertOrIgnore` compiles to `insert or ignore` (SQLite) / `insert ignore` (MySQL); both are covered by Laravel's grammar.

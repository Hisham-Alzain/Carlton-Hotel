# 09.1-04 — DELETE /api/auth/guest/me (D-06, D-09, D-10)

## Files

- `routes/api.php`: `Route::delete('/me', [GuestAuthController::class, 'deleteAccount'])->middleware('throttle:5,1')` inside the `auth:guests` group.
- `app/Http/Requests/Auth/DeleteGuestAccountRequest.php`: `confirm` required|accepted; `attributes()` maps `confirm` to `custom.attributes.confirm`.
- `app/Http/Controllers/Auth/GuestAuthController.php`: `deleteAccount()` → 200 `custom.auth.account_deleted`, `data: null`.
- `app/Services/Auth/AuthGuestService.php`: `deleteAccount()` delegates to the action.
- `app/Base/BaseRequest.php`: `accepted` mapped to `custom.validation.accepted`; the key was added to all 5 lang files.
- Test `tests/Feature/Auth/GuestAccountDeletionTest.php` (20).

`route:list --path=auth/guest/me` shows GET and DELETE.

## Deviations

- `ValidationMessageLocalizationTest` requires every reachable rule to be in `BaseRequest::messages()`. The new `accepted` rule needed a mapping plus `custom.validation.accepted` in 5 locales. Neither file is in the plan's list.
- `custom.attributes.*` was not wired anywhere, so attribute names rendered raw. The request now declares `attributes()` (the FX request does the same).

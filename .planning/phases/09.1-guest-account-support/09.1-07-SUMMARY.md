# 09.1-07 — staff exchange-rate routes (D-15..D-19)

## Routes (auth:users + permission:pricing.edit)

- GET `/api/cms/exchange-rates`: the board, with `note` and `set_by`.
- GET `/api/cms/exchange-rates/history`: paginated newest first, `currency` eq/in.
- POST `/api/cms/exchange-rates`: append-only, 201, message `custom.messages.exchange_rate_recorded`.

## Files

`Admin/ExchangeRateController` (on BaseController), `Requests/Currency/StoreExchangeRateRequest`, `Resources/Currency/ExchangeRateResource` + `ExchangeRateBoardResource`, `Services/Currency/ExchangeRateService`, `Actions/Currency/RecordExchangeRateAction` (bcmath scale 6, latest row `lockForUpdate`, signed `change_percent`), `Filters/ExchangeRateFilter`. `CmsAccessControlTest::$notYetBuilt` is now `[]`.

Tests: `tests/Feature/Currency/StaffExchangeRatesTest.php` (50), `tests/Unit/Currency/RecordExchangeRateActionTest.php` (9). Green, as are `CmsAccessControlTest` and the permission suites. The catalogue stays 30/13 and the presets are unchanged.

## Notes

- The rate rule is one regex that also rejects zero (`^(?!0+(?:\.0+)?$)\d{1,14}(?:\.\d{1,6})?$`), so no new validation rule needs a message mapping. A JSON number is turned into a string before validation.
- The store responds through `success()` directly, because `respondFromService()` would swap the message for `custom.messages.created` on a 201.
- `change_percent` is signed (`-99.000000` for 13000 → 130).

# Phase 9.1 — Validation Strategy

> Per-phase validation contract. Source: `09.1-CONTEXT.md` D-01..D-23 (final; Opus stand-in for Fable, no council).

## Test infrastructure

| Property | Value |
|----------|-------|
| Framework | PHPUnit 12 via `php artisan test` (Laravel 13), SQLite `:memory:` |
| Config | `backend/phpunit.xml` |
| Quick run | `cd backend && php artisan test --filter=<Class>` |
| Full suite | `cd backend && php artisan test` (phase gate only, in 09.1-09) |
| Baseline | 2376 green at Phase 9 close; 09.1-01 Task 1 re-measures and records it |
| Helpers | `RecordsRowLocks`, `CountsDomainQueries`, `Storage::fake('public')`, `travelTo`, `NullFirebaseService` (or a recording fake bound in the test) |

## Sampling

- After every task: run that plan's test classes (`--filter`).
- After every plan: the plan's classes, plus `LocaleFoundationTest`, `CmsAccessControlTest`, `SeederTest` when the plan touches lang, routes or permissions.
- Phase gate: the full suite stays green, and the count is the baseline plus the new tests and nothing else.

## Flagged Assumptions

- **FA-10.05-1.** With earning off the action writes nothing (no `loyalty.earn_skipped_inactive` log): CONTEXT requires a log only for the cancelled case, and a write on every settle of an unconfigured program would be audit noise. Recorded as a planner choice.
- **FA-10.05-2.** Manual folio lines count in `service` by their sign (Q11 names positive manual lines; a negative manual line, if one ever exists, reduces service before the clamp).
- **FA-10.05-3.** True concurrent double-settle is MySQL-only; on SQLite the second request is serialised and asserted via `folio_settled` + the unique keys (10-VALIDATION manual list).

- Send path: `SendMessageAction::write()` calls `$message->conversation()->associate($conversation)` (`SendMessageAction.php:58`), which sets the relation - no query needed.
- History paths: `ChatService::myConversationHistory()` and `adminHistory()` paginate `$conversation->messages()` (`ChatService.php:32-37, 44-47`) without the inverse relation set - reading `$message->conversation` there would lazy-load once per message. Resources must never query.

Service-request filter (IT6-05):
- Guest list: `ServiceRequestService::myRequests(Guest)` = `where guest_id` + `with('serviceItem.category')` + `latest()` + `paginate(15)` (`backend/app/Services/Service/ServiceRequestService.php:20-26`); controller passes no params (`backend/app/Http/Controllers/Api/ServiceRequestController.php:22-29`). Route tier S: `auth:guests` + `is_checked_in` (`routes/api.php:716`).
- **Correction:** there is no existing "unknown status -> 422" behaviour. The staff `ServiceRequestFilter` documents "an unknown value matches nothing" (`backend/app/Filters/ServiceRequestFilter.php:16-17`, same in `ReservationFilter.php:13-16`). The existing 422 mechanism is BaseFilter rule 3 "uninterpretable value -> 422 validation_failed" via `reject()` (`backend/app/Base/BaseFilter.php:36-39, 438-441`), with enum-check precedents `GuestFilter.php:53-56` and `ReservationFilter.php:56-58` (message `custom.validation.in`). Use that mechanism.
- Do NOT reuse `ServiceRequestFilter` on the guest route: it whitelists staff params (`assignee` by staff uuid, `guest` name search, `room`, `department`, `priority`, `type`, sort), and adding an enum check there would change the staff board contract. A dedicated guest filter (whitelist `status` only) is least privilege. This is a deliberate deviation from "one filter per model" (LoyaltyLedgerFilter shows filters may be audience-specific).
- `ServiceRequestStatus` values: `new, in_progress, completed, cancelled` (`backend/app/Enums/ServiceRequestStatus.php`), `values()` from `HasValues`.
- BaseFilter `in` casts each item through `cast()` (`BaseFilter.php:206-221`), `eq` through `cast()` too (`:195`); reject keys are `status` (shorthand) or `status.in` / `status.eq` (bracket form) (`:145-147`).
- Pint: no `pint` composer script; run `vendor/bin/pint` on NEW files only; do not reformat edited pre-existing files (hand-aligned style, some CRLF). Preserve line endings.
